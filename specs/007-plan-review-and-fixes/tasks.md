**Input**: Design documents from `specs/007-plan-review-and-fixes/`

**Tests**: every task ships its own `tests/*.test.sh` checks ("when …, then …", through
`tests/helpers.sh`), seen failing with the behavior disabled (constitution), in the same PR.

**Rules every task follows**:
- Each script change is made in `extension/scripts/` and in its project copy
  `.specify/extensions/landspec/scripts/`, kept identical (`diff -r extension/scripts
  .specify/extensions/landspec/scripts` prints nothing). Each change to
  `extension/commands/review.md` goes to its project copy and to the generated
  `.specify/extensions/landspec/.specify-dev/agent-commands/claude/speckit-landspec-review/SKILL.md`.

  `jq`; busybox `diff` prints unified output only.
- `docs/reference.md` changes in the same PR as the behavior it documents.
- Expected values in tests are literals, never computed by the code under test.
