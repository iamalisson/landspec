# landspec 2.7.0

## Fixes

- #186 a plan review is recorded only for the plan it read: the reviewer copies `plan.md` and
  `tasks.md`, hashes the copies with the new read-only `review.sh state --plan [<dir>]`, reviews
  them and writes `Plan state: <hash>`; `review.sh record --plan` refuses a report whose state is
  missing or no longer the plan's. A plan report written before this version has no such line and
  is refused once: run the plan review again. A project whose plugin is upgraded but whose copy of
  `review.sh` has no `state` action gets `Plan state: unavailable` reports until `/landspec:init`
  updates it.
